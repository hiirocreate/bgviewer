# BGViewer（BGRecorder専用の閲覧アプリ）

BGRecorderで撮った動画を見るための、**専用の閲覧アプリ**です。

このアプリ単体では何も撮影しません。BGRecorderが保存した動画を読み込んで一覧表示・再生するだけの
「ビューアー」です。BGRecorderとセットでインストールして使ってください。

---

## なぜ2つのアプリに分かれているのか（重要）

「録画データは、このBGViewerアプリからしか見られないようにしてほしい」という要望に応えるため、
次のような仕組みにしています。

1. BGRecorderは録画した動画を、**自分の内部ストレージ**（他のアプリからはroot無しでは絶対に見えない領域）
   に保存します。「アルバム」やGalleryアプリ、ファイル管理アプリなど、他のどのアプリの一覧にも一切出てきません。
2. BGRecorderは、その動画データを**signature権限**という仕組みで外部に公開しています。これは
   「BGRecorderと全く同じ鍵（証明書）で署名されたアプリだけ」が自動的に取得できる特別な権限です。
3. BGViewer（このアプリ）は、BGRecorderと**全く同じkeystoreファイル**で署名してビルドされるため、
   この権限を自動的に持ち、動画の一覧取得・再生ができます。
4. それ以外のアプリ（Gallery・他の動画プレイヤー・ファイル管理アプリ・録画アプリのログ機能なども含め、
   文字通りBGRecorderと同じ鍵を持たない全てのアプリ）は、この権限を絶対に取得できません。
   OSレベルでアクセスが拒否されるため、抜け道はありません。

つまり「BGRecorderで撮った動画は、BGViewerでしか見られない」という制約は、UIを頑張って隠しているのではなく、
Android自体の権限の仕組みで技術的に保証されています。

再生画面自体にも`FLAG_SECURE`という設定を入れており、この画面はスクリーンショットや他アプリによる
画面録画にも一切写りません。また、共有・保存・エクスポートといった「他アプリに渡す」ボタンは
意図的に一つも用意していません（用意してしまうと、そこから他アプリに動画が渡ってしまい、上記の
「BGViewerでしか見られない」という前提が崩れてしまうためです）。

## セットアップ手順（BGRecorderと同じ流れです）

**重要：BGRecorderと同じ鍵で署名する必要があるため、お渡ししたzipの中の`keystore/release.keystore`は
絶対に別のものに差し替えないでください。** このzipのkeystoreはBGRecorder用のzipに入っているものと
完全に同じファイルです。

### 1. 新しいGitHubリポジトリを作る
`bgviewer` などお好きな名前で、Public/Privateどちらでも構いません。

### 2. ファイルをアップロードする
zipを展開すると `bgviewer` フォルダが出てきます。**そのフォルダを開いて、中に入っている
`app`・`gradle`・`.github`・`keystore`などを全部選択してから**アップロードしてください
（`bgviewer`フォルダそのものをドラッグすると1階層余計になってしまうので注意してください）。

`.github`フォルダが見えない場合は、パソコンの隠しフォルダ表示をオンにしてください。

- Mac: Finderで `Cmd + Shift + .`
- Windows: エクスプローラーの「表示」→「隠しファイル」にチェック

### 3. ビルドを待つ
「Actions」タブを開き、「Build APK」が自動的に走るのを待ちます（数分程度）。

### 4. APKをダウンロード・インストール
成功したら、実行結果の「Artifacts」欄から`BGViewer-apk`をダウンロードし、スマホにインストールしてください。
権限の許可を求めるダイアログは出ません（signature権限はBGRecorderと同じ鍵で署名されていれば自動的に付与されるためです）。

**BGRecorderが先にインストールされている必要があります。** まだの場合は先にBGRecorderをビルド・インストールしてください。

---

## 使い方

1. アプリを開くと、BGRecorderで撮った動画の一覧が新しい順に表示されます（日時・長さ・容量）
2. タップすると再生画面が開きます
3. 一覧で動画を長押しすると削除できます（元に戻せません）
4. BGRecorderがインストールされていない場合や、録画がまだ無い場合はその旨のメッセージが表示されます

## ビルドエラーが出たら

そのまま送ってもらえれば直します。
